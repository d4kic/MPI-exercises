# MPI exercises
Message-Passing Programming with MPI.
## How to run
Enter solution code into MPI_Proj/main.c and build solution. Then open cmd in MPI_Proj/Debug and run:

```powershell
mpiexec -n <number of processors> MPI_Proj.exe
```
